# ArUco Marker Detection and Camera Calibration System

A computer vision system for camera calibration and ArUco marker detection. This project helps you:
- Calibrate cameras to remove distortion
- Generate ArUco markers
- Detect markers in real-time video streams

## 📋 Prerequisites
- Python 3.8+
- pip package manager
- Webcam or video input device

## 🛠️ Installation

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/aruco-project.git
cd aruco-project
```

### 2. Create Virtual Environment
```bash
python3 -m venv aruco-env
```
#### Activate Environment:
```bash
source aruco-env/bin/activate
```

### 3. Create Virtual Environment
```bash
pip install --upgrade pip
pip install -r requirements.txt
```
