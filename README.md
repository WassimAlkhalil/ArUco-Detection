## Aruco Marker Detection and Pose Estimation

### Project Overview
This project focuses on the detection and pose estimation of Aruco markers using computer vision techniques. It provides a complete pipeline for camera calibration, Aruco marker generation and pose estimation. The system is designed to work with OpenCV and Python, enabling accurate object localisation in 2D and 3D environments.

### Features
- Camera Calibration: Uses the Zhang calibration algorithm to correct camera distortions.
- Aruco Marker Generation: Generates custom Aruco markers for testing and validation.
- Pose Estimation: Computes 3D positions of markers using OpenCV's Aruco module.
- Distance Measurement: Measures distances between detected markers.
- Marker Detection: Identifies and tracks Aruco markers in real-time.
